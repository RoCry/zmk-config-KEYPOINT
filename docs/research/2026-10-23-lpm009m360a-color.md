# LPM009M360A 八色能力调研

2026-10-23。范围：原厂面板协议与当前代码事实；不修改固件、不选定实现方案、不定义新应用协议。

## 结论与资料

仓库指定的 **LPM009M360A 支持八色**：R/G/B 三个子像素分别取一位，可通过紧凑的 3-bit RGB 或带填充位的 4-bit RGB/D 输入。现有单色链路扩展到八色，在面板协议上可行；只修改 `color_mode` 不会产生正确的彩色像素或缓冲区。

原始资料：[Japan Display LPM009M360A 规格书，revision 03，SSCC 托管 PDF](https://www.sscc.co.jp/wp-content/themes/sscc-template/assets/images/business/otherproducts/jdimiplcd/download/LPM009M360A_specification_20180215.pdf)。下文均为**规格书印刷页码**，PDF 阅读器页码需加 4，例如印刷 p10 = PDF 第 14 页。模式表、时序图、地址表已对照 PDF 渲染图核实。

## 尺寸、方向与颜色

- p1 §1.1：0.850 英寸反射式 LTPS Memory-in-Pixel 面板，**水平 72 × 垂直 144 RGB 像素**；外形 12.455 × 24.01 × 0.844 mm，不含 FPC 与局部突出部分。p3 §1.3 显示 H1–H72、V1–V144，每像素包含 RGB 条纹，图示观察方向为屏幕正面、FPC 在下。因此仓库的 144 × 72 逻辑画布涉及 90° 旋转，不能按原生每行 144 像素发送。
- p10 §6.1、p11 §6.2：像素位序为 **R、G、B**，低电平表示黑。由此得到八种组合：`000` 黑、`001` 蓝、`010` 绿、`011` 青、`100` 红、`101` 品红、`110` 黄、`111` 白。八色来自三个二值通道，不代表任意 RGB 灰阶。

## 原厂输入模式与行帧格式

依据 p9 §5.1 模式/功能表、p10–11 §§6.1–6.2、p14–15 §§6.5–6.6：

| 输入模式 | M0 M1 M2 M3 M4 M5，未用位取零 | 首字节，AG9/8 为零 | 每原生行载荷 |
| --- | --- | --- | --- |
| 紧凑 RGB | `1 0 0 0 0 0` | `0x80` | 72 × 3 = 216 bit = **27 byte** |
| 单色 | `1 0 0 0 1 0` | `0x88` | 72 bit = **9 byte** |
| RGB + Dummy | `1 0 0 1 0 0` | `0x90` | 72 × 4 = 288 bit = **36 byte** |

首个行头依次发送 **6 位模式 M0→M5、10 位地址 AG9→AG0**。换算为 MSB-first 字节流，即 `[模式字节, 行地址]`；p21 §8 地址表确认有效行地址为 **1–144**，普通二进制编码，不进行 Sharp 类面板的地址位反转。本面板 AG9/8 均为零；p9 建议未用位取零。

SCS 在整个事务中保持**高电平**：

1. 首行：16 位模式/地址头，随后发送该行 27 byte RGB 或 36 byte RGB/D。
2. 后续每行：**6 位 Dummy + 10 位新行地址**，随后发送该行载荷；字节表示可为 `[0x00, 行地址]`。
3. 最后一个像素后必须再有 **16 个 Dummy 时钟**，然后拉低 SCS。单行事务同样需要末尾 16 个时钟。

RGB/D 的像素位序是 **R、G、B、Dummy**，Dummy 可为高或低（p14–15）。Dummy 为零时，两像素可表示为一字节 `R1 G1 B1 0 R2 G2 B2 0`；显示能力仍为八色。

按规格计算，整屏载荷分别为 3,888 byte（RGB）、5,184 byte（RGB/D）、1,296 byte（单色）。含每行 16 位头和末尾 16 个时钟的 144 行事务，RGB / RGB/D 共 4,178 / 5,474 byte；1 MHz 理想线速耗时约 33.4 / 43.8 ms，不含驱动开销。紧凑 RGB 比 RGB/D 少 25% 载荷；本文不选择实现方式。

## 电气时序与 COM 反转

- p7 §4.2：在 VDD=3.0 V、25°C 条件下，SCLK 典型 **1 MHz**、最高 **2 MHz**；注释指出低温且电压低于 3.0 V 时，最高频率可能进一步降低。当前 overlay 的 **4 MHz** 超出该规格上限。
- p7：SCS 低电平间隔 ≥6 µs，SCS 拉高至时钟开始 ≥6 µs，最后时钟至 SCS 释放保持 ≥2 µs；SI 建立 ≥200 ns、保持 ≥250 ns；SCLK 高/低电平各 ≥250 ns。时序图为时钟空闲低、上升沿采样，符合 mode 0 / MSB-first；尚无实际总线测量。
- p7、p20 §7.1：COM 极性由 **EXTCOMIN 上升沿**翻转，内部电路控制正负极性，正负周期应尽量等长。EXTCOMIN 频率 1–140 Hz，对应 COM 0.5–70 Hz。更新模式中的 M1 明确为无效位（p10–15）；沿用 Sharp 的 `CMD_VCOM` 名称不能证明该 SPI 位能执行 JDI 极性反转。
- p8 §4.3：上电初始化要求 all-clear ≥1 ms，内部锁存释放 ≥30 µs、COM 初始化 ≥30 µs；DISP 为低时忽略 EXTCOMIN。p10–15 说明输入模式标志随 **DISP 拉低**清除，因此冷启动或运行时切换输入模式需核实实际接线和控制序列。

## 当前已知限制与未验证项

- 当前驱动 `9 * 144` 缓冲区只容纳单色。通用非单色分支每行发送 **36 byte**，对应 RGB/D（`0x90`），并不对应紧凑 RGB（`0x80` / 27 byte）；存在该分支不等于已经实现八色。
- 仓库 compatible 字符串说明预期型号，不能替代实物身份核验。两块实际面板型号、DISP/EXTCOMIN 接线、振荡/极性反转、两半键盘供电与休眠路径、实际 SCS 时序均未实测。
- 八色输出、旋转、局部刷新、冷启动与唤醒仍需后续固件构建和实屏验证。本文没有提供固件编译、刷机、逻辑分析仪、摄像头或耗电测量证据。
