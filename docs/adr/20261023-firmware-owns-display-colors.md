# 固件统一决定显示配色，发送端表达状态

Date: 2026-10-23
Status: Accepted

Context: 八色升级同时影响屏幕控件和主机卡片协议；允许发送端直接指定颜色会把配色规则分散到各个数据源。

Decision: 固件拥有颜色与视觉样式。发送端表达数据和语义状态；若需要逐元素差异，扩展元素语义。左右屏沿用现有布局，本轮同时升级状态 UI 与八色图片工具。

Consequences: 配色可以在固件内统一调整，发送端无法任意指定每行颜色。当前 KP3 只有整卡状态；是否引入元素级状态须另行明确，不能由绘图层猜测百分比含义。固件与 producer 如需更改协议，联合升级。
